# Simulated data: AeroParts transport history

Fictional aerospace manufacturer, 9 production sites (7 in France, 2 in the
Maghreb), 18 months of shipments (2025-01 to 2026-06): about 54,000 shipments
and 12 MEUR of transport per year, ~80% of it express and air freight.
Product families cover mechanical parts, mechatronics, electronics and
optics/optronics, made in series or to order. Generated by
`scripts/generate_data.py` (deterministic, seed 42, about one minute).
No real company data.

```bash
pip install pandas numpy
python scripts/generate_data.py
```

The large generated files (orders, shipments, SQLite database and the hidden
truth file) are not committed; the script rebuilds them identically.

## Tables the agent can query (`data/transport.db`, also as CSV)

| table | one row per | key fields |
|---|---|---|
| `sites` | production site | site_id, country |
| `customers` | customer delivery point | customer_id, country |
| `carriers` | carrier | carrier_id, carrier_type (integrateur, expressiste, messagerie, routier, commissionnaire, ferroviaire, petit_local), modes |
| `lanes` | origin x destination x mode | flow_type (intersite / client), standard_lead_days, distance_km |
| `rate_card` | mode | reference cost model: fixed_eur + kg x (eur_per_kg + eur_per_kg_per_1000km x distance/1000) |
| `emission_factors` | mode | kg CO2e per tonne-km (activity-based method) |
| `spend_carbon_factor` | month | kg CO2e per EUR (spend-based method, drifts over time) |
| `product_families` | product family | product_type: serie or commande |
| `orders` | order | need_date, planned_ready_date, actual_ready_date, production_delay_days |
| `shipments` | shipment | mode, carrier, ship/delivery/need dates, weight_kg, cost_eur, co2_activity_kg, co2_spend_kg |

## Weekly shuttle to Casablanca

A consolidated road + ferry shuttle leaves Toulouse for Casablanca every
Wednesday (mode `navette`, operated by Trans-Maghreb Road, 5 days transit).
It is reserved for Toulouse and excludes optronic products (FAM-OPT). Other
French sites ship to Casablanca on their own.

## Maghreb to customers

Shipments from the Maghreb sites to customers go by air as a business rule;
sea freight is rare.

## How urgency works

Urgency is not declared, it is computed: an order is ready on
`actual_ready_date` and needed on `need_date`. If a cheaper mode's
`standard_lead_days` fits in that slack, express was avoidable; if none
fits, express made up for a production delay.

## Known data quality issues (on purpose)

Missing weights (~2%), carrier name spelling variants, duplicated shipment
rows (~0.5%). The agent is expected to notice and report them.

## Hidden scenarios

The answers live in `eval/ground_truth.json` and `eval/shipments_truth.csv`,
which are never exposed to the agent.
